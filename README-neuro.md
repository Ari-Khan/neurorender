# NeuroRender

Draw a 2-D schematic of a nervous system → generate a synthetic
connectome → train it with an **intrinsic selectivity reward only** so
that distinct stimuli elicit distinct motor-pool responses.

Current target specimen: *Hypsibius exemplaris* (tardigrade), ≤1000
neurons, from a 2-D point schematic (points + connections + region
types).

---

## ⚠️ Honesty statement — read this before citing anything

**The connectome is synthetic and anatomy-constrained, not measured.**
No electron-microscopy connectome of *H. exemplaris* exists at cellular
resolution; the points, positions, tract types and edge weights in
`data/sample_tardigrade.json` are generated by `scripts/make_sample.py`
under anatomical constraints (brain / ventral nerve cord / outer nerve
regions, crossed inhibitory interneurons, ipsilateral afferents,
Dale's law). Tract scales, E/I ratios and motor-pool weights are
plausible priors, **not data**. Nothing in this repository should be
read as a claim about the real animal's wiring or physiology.

**The reward is intrinsic-only.** There are no supervised targets, no
task-accuracy reward, no hand-specified "correct" motor pattern, and no
physical motion or body model. The network is rewarded solely for *make
your readout responses carry information about which stimulus was
presented* (Fisher-style discriminability + leave-one-replicate-out
nearest-centroid decoding, bounded by anti-silent / anti-seizure
penalties; see `neurorender/reward.py`). Any resemblance between the
trained responses and real tardigrade behaviour is currently
**coincidental-structural at best** and is not evidence of anything.

**"Emergent" claims require held-out tests and ablations.** Training
reward improvements alone are *not* evidence of generalisation — the
objective is deterministic (fixed noise across generations), so ES can
exploit seed-specific quirks. The project discipline, enforced by
`scripts/eval_heldout.py` and `scripts/test_contamination.py`:

1. Gains must replicate on **unseen noise seeds** (disjoint from the
   training seed and the in-demo eval seed).
2. Gains must survive **held-out stimulus intensities** and
   **unseen stimulus combinations** (e.g. conflicting light-left +
   chemB-right), not just the training panel.
3. Gains must be **attributable** via ablation (neutralise one
   parameter group at a time) and must *not* depend on a single fragile
   pathway.
4. Simulator correctness is guarded by **contamination invariants**
   (candidate/condition/replicate purity, bit-exact determinism) that
   catch indexing bugs of the kind already encountered and fixed
   (cross-trial bincount stride; see `scripts/test_contamination.py`).
5. Trained-vs-baseline comparisons use **paired seeds** everywhere.

Results that fail these checks are reported as failures, not smoothed
over. Where the training-seed number and the held-out number diverge,
both are quoted (they did diverge early on: a reps=3 run showed
+0.20 decoder accuracy on its training seed but only +0.03 on unseen
seeds; reps=6 fixed this).

**Known open weaknesses** (tracked, not hidden): generalisation to
**held-out stimulus intensities currently regresses** (see Current
status); the trained solution concentrates the readout code on ~2 of 10
motor cells; the light modality is weak at the readout (1 photoreceptor
per side vs 2 chemosensory cells per side); ablations show the gain
leans heavily on the outer-nerve afferent tract.

## Quickstart

```bash
pip install -r requirements.txt        # numpy, matplotlib (Agg backend)

python scripts/make_sample.py                       # (re)generate the sample connectome
python scripts/run_demo.py --gens 60 --pop 20 --reps 6 --seed 0 --out out-run
python scripts/eval_heldout.py --ckpt out-run --out out-run/heldout
python scripts/test_contamination.py                # simulator integrity invariants
```

No torch / scipy / cma required — CMA-ES is implemented in
`neurorender/cmaes.py` (dependency-free).

> Note: regenerating `data/sample_tardigrade.json` changes node/edge
> counts and E/I draws; checkpoints trained on a previous sample are
> not directly comparable.

## Repository layout

```
neurorender/
  schema.py       connectome JSON load/validate; infers missing
                  role/side/nt/tract-type from the graph (E/I drawn at
                  random with region-dependent priors when absent -
                  pin `nt` explicitly for anything you care about)
  network.py      flat arrays for the simulator (bias, weights, masks,
                  sensory/readout groups, region indices)
  izhikevich.py   Izhikevich neurons (RS for E, FS for I), conductance
                  synapses + Tsodyks-Markram STP, ligand-gated chemical
                  conductances (A exc / B inh), light = injected current
  stimuli.py      Condition dataclass + trial-batch construction
                  (layout: trial p = cand*(C*R) + cond*R + rep)
  reward.py       intrinsic selectivity objective (Fisher ratio +
                  LOO nearest-centroid decode, activity penalties)
  train.py        ParamSpace (pathway / default / edges) + CMA-ES loop
                  with common random numbers across candidates and a
                  fixed noise seed across generations
  cmaes.py        compact CMA-ES, numpy only
  metrics.py      text summaries and figures
scripts/
  make_sample.py  synthetic tardigrade-like connectome generator
  run_demo.py     end-to-end CLI: baseline -> train -> held-out eval
  eval_heldout.py held-out seeds / intensities / conflicting stimuli
                  + parameter-group ablations
  test_contamination.py  simulator purity invariants
```

## Model summary

* **Neurons**: Izhikevich (2003) canonical model; regular-spiking
  excitatory, fast-spiking inhibitory (Dale's law: the class belongs to
  the neuron, set in the schema).
* **Synapses**: conductance-based, Tsodyks-Markram short-term
  plasticity (depression + facilitation) per synapse.
* **Stimuli**: light = current step at photoreceptors; chemical =
  concentration step producing slow ligand-gated conductances (species
  A excitatory, species B inhibitory).
* **Readout**: mean firing rates of the designated motor pools in the
  stimulus window; that is the only place the reward looks.

## Training

CMA-ES optimises a low-dimensional gain vector *around the generated
wiring* (the wiring itself is frozen):

| mode      | parameters                                        |
|-----------|---------------------------------------------------|
| `pathway` | one log-gain per tract type (3)                   |
| `default` | pathway + global E/I balance + per-sensory gains (10) |
| `edges`   | default + one log-gain per synapse                |

Deterministic objective: fixed noise seed across generations, common
random numbers across candidates — fair ranking, but see the
generalisation discipline above.

## Current status (sample: 90 nodes / 288 edges; noise σ=1.3)

Latest training run `out-v2-default` (mode=default, 10 params, gens=60,
pop=20, reps=6, seed=0) and its held-out evaluation
(`out-agent2/heldout-v2-default/heldout.json`):

| panel | baseline (θ=0) | trained | verdict |
|---|---|---|---|
| demo eval, unseen eval seeds (n=16) — decoder acc | 0.66 | **0.73** | ✅ |
| **unseen noise seeds** 9000–9005 — reward | 0.875 ± 0.07 | **1.010 ± 0.05** (Δ > 0 on 6/6 seeds) | ✅ |
| … — decoder acc | 0.694 ± 0.06 | **0.736 ± 0.04** (Δ ≥ 0 on 6/6) | ✅ |
| **conflicting/multimodal** (7 conds, chance 0.143) — acc | 0.768 | **0.857** | ✅ |
| **held-out intensities** (12 conds, chance 0.083) — acc | 0.438 | 0.365 | ❌ regressed |

Ablations (seed 9102): the gain is attributable mostly to the
**outer-nerve afferent tract gain** (ablating it: reward −0.64) and the
**global E/I balance** (−0.31); ventral tract small (−0.08); individual
sensory gains ≈ 0. So the solution is not one-single-pathway-fragile,
but neither is it distributed.

**Honest caveats (tracked, not hidden):**

* **Held-out intensities regress** — the trained θ specialises to the
  training stimulus intensities; generalisation across intensity is an
  open problem, not a solved one.
* The readout response **sparsifies**: after training 2 of 10 motor
  cells carry most of the discriminative rate (the anti-runaway penalty
  caps per-cell peak at 50 Hz, so this is not single-cell blow-up, but
  it is a concentration, not a distributed code).
* The objective is deterministic per-seed (fixed noise across
  generations), so in-seed improvements are optimisable by
  construction — only the held-out-seed rows above count as evidence.
* Checkpoints `out/`, `out-default/`, `out-edges/`, `out-fix*/` predate
  fixes (cross-trial contamination in `izhikevich.py`; reward-hack
  anti-runaway penalty) and are **invalid** — do not quote them.
